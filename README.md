# 🌿 Air Quality Monitor

A simple and user-friendly web application that allows users to check the latest available air-quality information for Indian cities and areas.

The application uses the **OpenWeather API** to retrieve air-pollution data and calculates a **CPCB-style AQI** using PM2.5 and PM10 values.

## ✨ Features

- 🌍 Search for Indian cities and areas
- 🔎 Place autocomplete suggestions
- 📍 Automatic location coordinates through geocoding
- 🌫️ PM2.5 and PM10 pollution data
- 📊 CPCB AQI calculation from PM2.5 and PM10
- 🟢 AQI category and color indicator
- 📈 Visual AQI scale from 0–500
- 💡 Simple explanation of what the AQI means
- 🌤️ OpenWeather AQI comparison
- 📱 Responsive design for mobile, tablet, and desktop
- ⚠️ Loading and error states
- ♿ Accessible search input and autocomplete

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
- OpenStreetMap Nominatim API
